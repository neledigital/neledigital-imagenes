# NeleDigital · Imágenes

Este repositorio aloja únicamente las imágenes generadas automáticamente para las publicaciones diarias de redes sociales de [NeleDigital](https://neledigital.com.co).

## ¿Por qué es público?

Necesita ser público para que las imágenes se puedan servir vía `raw.githubusercontent.com` sin autenticación — así Buffer y las redes sociales (Facebook, LinkedIn, Twitter/X) pueden descargarlas al publicar cada post.

## ¿Qué hay acá?

Solo imágenes (fotos genéricas generadas por IA, con el logo de NeleDigital superpuesto) usadas en las publicaciones del día. No contiene código, credenciales, ni información del negocio — eso vive en un repositorio privado aparte.

## Mantenimiento

Las imágenes se borran automáticamente después de 7 días — cada día solo se usa la del día actual, así que no se acumula historial innecesario.
